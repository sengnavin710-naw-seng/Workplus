# Workforce Database Resources

## Knowledge

- [Better Auth email and password](https://better-auth.com/docs/authentication/email-password)
  เอกสารหลักสำหรับการเปิดใช้งาน email/password, sign-in และ sign-up flow
- [Better Auth session management](https://better-auth.com/docs/concepts/session-management)
  เอกสารหลักสำหรับ session lifecycle, expiration และการยกเลิก session
- [Better Auth organization plugin](https://better-auth.com/docs/beta/plugins/organization)
  เอกสารหลักสำหรับ organization, member, invitation และ access control

- [Drizzle Studio overview](https://orm.drizzle.team/drizzle-studio/overview)
  เอกสารหลักสำหรับการเปิดดู เพิ่ม แก้ไข และลบข้อมูลผ่าน Drizzle Studio ใช้เมื่อเรียนรู้หน้าจอและความสามารถของ Studio
- [Drizzle Kit Studio command](https://orm.drizzle.team/docs/drizzle-kit-studio)
  อธิบายการเชื่อมต่อและ local proxy ของ Studio ใช้เมื่อตรวจปัญหาการเปิด Studio
- [Drizzle schema declaration](https://orm.drizzle.team/docs/sql-schema-declaration)
  อธิบาย schema ที่ประกาศใน TypeScript ใช้เมื่อเรียนรู้ table, column, constraint และ source of truth ของโปรเจกต์
- [Drizzle Kit overview](https://orm.drizzle.team/docs/kit-overview)
  แยกหน้าที่ของ `push`, `studio`, `pull`, `export` และคำสั่งจัดการ schema อื่น ๆ
- [Drizzle Kit push](https://orm.drizzle.team/docs/drizzle-kit-push)
  อธิบายขั้นตอนเปรียบเทียบ schema TypeScript กับฐานข้อมูลและการนำ SQL ไปใช้โดยไม่สร้าง migration files
- [Drizzle migrations fundamentals](https://orm.drizzle.team/docs/migrations)
  เปรียบเทียบ codebase-first, database-first และ migration-file workflows ใช้เมื่อโครงการเริ่มเตรียม production

## Wisdom (Communities)
