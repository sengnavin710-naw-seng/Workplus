เมนูด้านซ้าย

ฟีเจอร์หลักในหน้าจอ

1

Spotlight

ค้นหาและกระโดดไปยัง table หรือเครื่องมืออย่างรวดเร็ว กด Ctrl+K เพื่อเปิด

2

SQL console

เขียน SQL โดยตรง เช่น SELECT เพื่ออ่านข้อมูล เป็นเครื่องมือทรงพลังและสามารถแก้หรือลบข้อมูลได้เช่นกัน

3

Drizzle runner

ทดลองคำสั่งด้วย Drizzle query API เหมาะเมื่อคุณเริ่มคุ้นกับ TypeScript และต้องการดู SQL ที่ Drizzle สร้าง

4

Schema

ดูโครงสร้าง table, column, type, primary key, foreign key และความสัมพันธ์ ไม่ใช่ข้อมูลแต่ละแถว

5

schema: public

ตัวเลือก namespace ของ PostgreSQL โปรเจกต์นี้เก็บตารางแอปไว้ใน public

6

Search / Refresh / +

ค้นหา table, โหลดรายการใหม่ และสร้าง table ผ่าน UI ตามลำดับ สำหรับโปรเจกต์นี้ไม่ควรใช้ปุ่ม + เพื่อสร้าง schema

ขั้นตอนถัดไป

ทำให้ตารางปรากฏอย่างถูกวิธี

หยุด Studio ด้วย Ctrl+C แล้วใช้ schema TypeScript ของโปรเจกต์สร้างตาราง จากนั้นเปิด Studio ใหม่

อ่าน SQL ที่ Drizzle แสดงก่อนยืนยัน โดยเฉพาะข้อความเตือนเกี่ยวกับการลบหรือเปลี่ยนชนิดข้อมูล
bun db:push

10 ตารางพื้นฐานของโปรเจกต์

invitationsคำเชิญเข้าร่วมองค์กร
teamsทีมภายในองค์กร
team_membersสมาชิกของแต่ละทีม
devicesข้อมูลลงทะเบียนอุปกรณ์ขั้นพื้นฐาน

แก้ schema ในโค้ด

แก้ที่ packages/db/src/schema/index.ts แล้วใช้ bun db:push เพื่อให้โค้ดกับฐานข้อมูลตรงกัน

!

อย่ากด Create table

การสร้างผ่าน UI ทำให้ฐานข้อมูลต่างจาก schema TypeScript และทีมติดตามการเปลี่ยนแปลงได้ยาก

!

ระวัง UPDATE / DELETE

Studio แก้และลบข้อมูลจริงทันที โดยเฉพาะคำสั่งที่ไม่มี WHERE อาจกระทบทุกแถว
